# Project Odyssey v1.2

This release combines the restored four-level Finish to Start minigame from v1.1 with the programme summary features.

## Restored summary features
- Completion count and programme progress bar.
- Lifecycle phase status for Initiation, Planning, Execution and Closure.
- Live Clinical Readiness percentage combining completion, quality, risk control, stakeholder support and schedule performance.
- Final NCB-101 Development Report after Closure.
- Printable project report showing duration, budget, quality, risk, support, readiness status and decision record.
- Project notebook reopens the final report after project completion.

## Enhanced arcade retained
- Scientist project-manager avatar.
- Four increasingly difficult levels.
- Yellow milestone diamonds, red triangular pitfalls, gaps and deadline ceiling.

## Deploy
Upload all files and folders to the repository root, commit to `main`, and configure GitHub Pages to deploy from `main` and `/(root)`. Use Restart after replacing an earlier version.
